# Gopherfish

The simple but unique fishing TUI game written in Go.

Build by [lotus64](https://github.com/lotus64yt) for [goship hackclub](https://goship.hackclub.com/).

### Installation

Download the latest release :
https://github.com/lotus64yt/gopherfish/releases/latest

then run the binary file in your terminal.

### How to play

Press play and use your mouse and click to catch the fish.
When you catch all the fish more will appear.

The kelp is a small obsacle where fish can hide behind.
